## Contexte

Alternance d'un an chez CGI, dans le cadre du BUT Informatique, sur une
application ferroviaire de la SNCF. J'y travaille sur la couche des web
services de l'application, aux côtés d'une équipe de développeurs
professionnels.

## Réalisations

**Mission A — Modernisation d'un web service SOAP existant**
- Montée de version Java 5 → Java 21.
- Migration vers Jakarta EE.
- Mise à jour d'Apache CXF et normalisation du build Maven.

**Mission B — Développement d'un nouveau web service REST**
- Stack Spring Boot + PostgreSQL.
- Opérations CRUD (lecture, écriture, recherche).
- Gestion d'erreurs structurée en JSON.

## Compétences mobilisées

C'est le projet où les trois compétences se recoupent le plus fortement :

- **Gérer des données** : conception des accès PostgreSQL, CRUD REST,
  cohérence des données entre l'ancien service SOAP et le nouveau service REST.
- **Conduire un projet** : gestion d'une mission de modernisation sur du code
  legacy en environnement de production, avec des contraintes réelles
  (compatibilité, non-régression).
- **Collaborer en équipe informatique** : intégration dans une équipe de
  développeurs professionnels, appropriation d'un existant que je n'ai pas
  conçu, avec des conventions et un processus de revue déjà en place.

## Posture réflexive

C'est le projet le plus formateur du parcours parce que les erreurs y ont un
coût réel : contrairement aux SAÉ, une régression sur ce service impacterait
une application en production utilisée par la SNCF. Cela m'a appris à
davantage tester avant de livrer et à documenter mes choix de migration pour
que l'équipe puisse les relire sans moi. Cette alternance est également le
seul projet de ma 3ème année à ce jour : mon portfolio de compétences BUT3
repose donc presque entièrement dessus, ce qui en fait la pièce centrale de
cette page — les prochaines SAÉ de 3ème année viendront l'enrichir.
