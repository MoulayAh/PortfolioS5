## Contexte

L'objectif de cette SAÉ était d'installer un poste virtuel Linux intégrant
MySQL, Apache2 et PHP, afin de pouvoir créer une base de données et un site
web utilisant PHP comme langage de script côté serveur.

## Réalisations

- Configuration individuelle de chaque logiciel (serveur web, SGBD, PHP).
- Création d'une base de données et d'un site affichant son contenu via
  Apache et PHP.

## Compétences mobilisées

Premier contact avec la **gestion de données** de bout en bout : de
l'installation du SGBD à la restitution des données dans une page web.

## Posture réflexive

Ce projet, très orienté « installation », m'a surtout appris la mécanique
d'une stack LAMP simplifiée. Le contenu technique (SQL, PHP) était encore
minimal — c'est un projet fondateur plus que démonstratif, que je garde pour
la cohérence chronologique du portfolio.
