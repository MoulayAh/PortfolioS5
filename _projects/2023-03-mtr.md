## Contexte

Projet de fin de première année : développer un jeu (« Mine ta Rouille ») en
mettant pour la première fois en pratique la programmation orientée objet.

## Réalisations

Version fonctionnelle du jeu, qui servira de base à un refactoring complet en
deuxième année (voir le projet *Refacto MTR*).

## Compétences mobilisées

Premiers choix de **conception orientée objet** structurant durablement le
projet — pour le meilleur et pour le pire, comme le montre le refactoring
nécessaire l'année suivante.

## Posture réflexive

Le code produit ici manquait de conventions claires et de documentation, ce
qui a directement motivé le travail de refactoring en BUT2. Ce projet est
surtout intéressant *a posteriori*, comme point de comparaison avec sa propre
suite.
